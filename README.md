# Leyla Çarşaf Geçirme Simülasyonu: KYK Edition 🛏️

Leyla için hazırlanmış, siyah-pembe temalı, mobil uyumlu ve tarayıcıda oynanabilen mini oyun.

## Oyna

GitHub Pages etkinleştirildikten sonra:
**https://kadirgurlu.github.io/leyla-carsaf-kyk-edition/**

## Nasıl oynanır?

1. Oyunu başlat.
2. Çarşaf üzerindeki pembe numaralı tutamaçları, aynı numaralı yatak köşelerine sürükle.
3. Dört köşeyi de zaman dolmadan oturt.
4. Üç bölümü tamamla: *Yatakla Tanışma*, *Lastik İsyanı*, *KYK Final Boss*.

Son bölümün sonunda Leyla'ya özel bir sürpriz mesajı bulunuyor.

## Teknoloji

- Tamamen bağımsız HTML, CSS, vanilla JavaScript ve SVG.
- Sürükle-bırak kontrolü: fare, dokunmatik ekran ve kalem.
- Harici kütüphane, backend veya çevrimiçi API gerektirmez.
- `index.html` dosyasını doğrudan tarayıcıda da açabilirsiniz.

## GitHub Pages kurulumu (tek seferlik)

Bu depo için GitHub **Settings → Pages → Build and deployment → Source → GitHub Actions** seçeneğini etkinleştirin.

Ardından **Actions → Deploy Leyla KYK Edition to GitHub Pages** iş akışını çalıştırın veya `main` dalına yeni değişiklik gönderin.

## Gizlilik

Bu depo **public** durumdadır ve Leyla'nın küçük portre fotoğrafı `index.html` dosyasına gömülüdür. Bu nedenle fotoğraf ve kaynak kodu herkes tarafından görüntülenebilir.

Kadir'den Leyla'ya, küçük bir moral sürprizi. ♥
